## 建議學習順序

1. 先理解 AI 與大模型的基本概念。
2. 再學 prompting techniques，掌握如何設計清楚、可控、可覆核的 prompt。
3. 接著看警務文書與資料處理應用，了解 LLM 如何協助整理、草擬、分析與核對。
4. 再進入 AI agents，學習工具使用、workflow、memory 與 verification。
5. 最後使用 Codex 練習把 AI 應用到程式、文件和自動化工作。
