ReAct 與 Reflexion 教學實驗室

以交通事務局即時停車場車位 API，比較「先調用工具查資料」與「先寫、再檢查、再修改」。

試用以下問題

  • ReAct：你是資料查核助理。任務：查詢「下環街市」目前的汽車位、電單車位、電動汽車位及無障礙車位。先用一句話列出查核計畫，再調用 get_macao_parking_spaces；取得 Observation 後才回答。輸出「查核計畫／工具觀察摘要／最終答案」，列出更新時間。不得補造；null 不可當作 0。
  • Reflexion：請根據以下資料寫一段 80 字內的即時車位資訊使用提示：車位數目會變動；使用前要查看更新時間；空值代表沒有資料，不等於零。請先寫初稿，再檢查三項提醒及是否補造資料，最後修訂。
  • 在兩種模式執行同一問題，然後比較過程紀錄。

可用工具

get_macao_parking_spaces

調用交通事務局「停車場車位資訊」API，按中文名稱查詢最新剩餘車位。

list_macao_parking_names

不知道正確名稱時，先列出可供查詢的停車場。

compare_macao_parking_spaces

比較 2 至 5 個停車場指定類型的剩餘車位。

過程紀錄

ReAct：停車場名稱 → 即時 API → 觀察車位及時間 → 回答。
Reflexion：初稿 → 檢查缺漏 → 修訂稿。
