# 課堂活動支援手冊（模擬資料）

## 場地預約

場地申請必須列明活動日期、開始及結束時間、預計人數、場地佈局及所需設備。在設施管理組確認前，預約只屬暫定。如預計人數超過場地列明的容量，職員必須建議其他場地，不得自行批准例外安排。

## 設備

投影機及咪高峰應在活動前至少一個工作天完成測試。視像會議申請必須列明使用的平台，以及是否有外部參加者。借用設備須於下一個工作天下午六時前歸還。

## 事故紀錄

活動事故紀錄應包含日期、時間、地點、可觀察事實、已採取行動及後續負責人。撰寫人員應區分直接觀察與他人轉述的資料。缺失資料必須標示為「未知」，不得自行補造。

## 上報

如有即時安全風險，應轉交值班主管處理。一般設備故障應先通知設施支援人員。紀錄須列明聯絡對象及聯絡時間。
