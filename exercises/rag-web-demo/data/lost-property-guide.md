# 失物處理教學指引（模擬資料）

## 初步紀錄

記錄物品種類、大約遺失時間、可能遺失地點、可辨識特徵及聯絡方法。如非必要，不應記錄完整身份證明文件號碼或銀行卡號碼。

## 拾獲物品

記錄拾獲物品的地點、時間，以及由誰把物品轉交職員。如適用程序有此要求，應向拾獲者提供收據或參考編號。在完成物主身份核實前，不得承諾一定會交還物品。

## 不確定資料

如報稱時間或地點與其他紀錄互相矛盾，應保留兩個版本，並標示矛盾之處供人工覆核。只有顏色或型號相似，不能證明兩份紀錄涉及同一物品。

## 公開資料

處理真實個案時，使用者必須查閱最新官方服務頁面及諮詢獲授權人員。本模擬指引只供提示工程教學使用，並非實際工作指令。
