# 透明 RAG 課堂示範

這是一個輕量 Node.js 專案，用瀏覽器展示完整 RAG 流程：

```text
網頁或文件 → 清理文字 → 分段 → 檢索 → 加入提示詞上下文 → 生成附引用答案
```

本專案使用透明的詞彙檢索器，學生毋須另設向量資料庫或嵌入模型，也可查看每個段落的檢索分數。OpenRouter 只用於生成答案。

## 系統要求

- Node.js 18 或以上版本
- OpenRouter API 金鑰
- 本專案只使用一般聊天生成，所選模型毋須支援工具調用
- `pdf-parse`（執行 `npm install` 時自動安裝），用於抽取可搜尋的 PDF 文字

## 執行方法

把 `.env.example` 複製為 `.env`，填入金鑰後執行：

```powershell
cd "rag-web-demo"
Copy-Item .env.example .env
# 編輯 .env，以真正金鑰取代 your_openrouter_key_here
npm start
```

伺服器會自動載入 `rag-web-demo` 資料夾內的 `.env`。如 PowerShell 已設定同名環境變數，PowerShell 的值會優先使用。

開啟 `http://localhost:3100`。

即使沒有 API 金鑰，文件匯入及檢索功能仍可使用，但不會生成 AI 答案。

## 建議匯入的公開網頁

- `https://www.gov.mo/zh-hant/entity-page/entity-424/`
- `https://www.gov.mo/zh-hant/services/ps-1475/`
- `https://www.fsm.gov.mo/psp/cht/psp_left_3_DP.html`

公開網站可能改版、封鎖自動下載，或包含大量導覽文字。因此專案亦附有模擬文件，確保課堂示範可以重現。

## 建議課堂活動

1. 使用內建知識庫提問：「根據澳門大學《性騷擾及性霸凌個案處理指引》，投訴一般須在事件發生後多久提出？如果投訴先交給部門主管，主管須在多少個工作日內轉交性別平等委員會？」
2. 檢視被檢索段落及其分數。
3. 匯入一個官方公開網頁。
4. 提出一個只能從新網頁回答的問題。
5. 移除問題中的關鍵詞，觀察檢索結果如何改變。
6. 把 RAG 答案與沒有取得檢索段落的一般模型答案比較。

### 澳門大學指引示範問題

專案已加入澳門大學《性騷擾及性霸凌個案處理指引》的課堂檢索文本及原始 PDF 來源。可直接提問：

```text
根據澳門大學《性騷擾及性霸凌個案處理指引》，投訴一般須在事件發生後多久提出？
如果投訴先交給部門主管，主管須在多少個工作日內轉交性別平等委員會？
請分點回答並標示資料來源。
```

網頁現在亦支援直接匯入或上載 PDF。原始文件網址：

`https://www.um.edu.mo/wp-content/uploads/2023/12/Guidelines_effective5-Dec2023.pdf`

## 安全與限制

- 只使用公開、非敏感的教學資料。
- 網址匯入只接受 HTTP(S)，封鎖常見私人網絡位址，12 秒後逾時，文件上限為 6 MB。
- 匯入文件只存於記憶體，重新啟動伺服器後便會消失。可按「下載知識庫」匯出 JSON。
- 簡易 HTML 抽取器不能處理依賴 JavaScript 顯示內容的網頁；文字型 PDF 可由 PDF 解析器處理，掃描圖片型 PDF 則需要額外 OCR。
- 網頁匯入會根據 HTTP 標頭或 HTML `<meta>` 自動識別 UTF-8、Big5／CP950 及 GB18030；介面會顯示實際使用的編碼。
- 詞彙檢索容易講解，但理解語義相似度的能力不及嵌入式檢索。
- 檢索所得文字並不可信。模型提示詞已明確禁止執行來源文件內嵌的指令。
